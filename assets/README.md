# Ассеты

## Сгенерированные ИИ (`ai/`)
- `bg_ai_paper.jpg`, `bg_ai_city.jpg`, `bg_ai_space.jpg`, `bg_ai_sunset.jpg` — фоны игры (540×960, JPEG q74)
- `thumb_ai_*.jpg` — превью фонов для экрана настроек (150×267)
- `btn_ai_*.png` — 6 кнопок в палитре PNG-8 (360 px шириной, ~5 КБ каждая)
- обработка: белый фон вырезан flood-fill, лишние цвета получены сдвигом
  оттенка в HLS, затем квантование в 64-цветную палитру

## Сгенерированные кодом (Pillow)
- `make_assets.py` — аватар, музыка (16000 Гц моно), звуковые эффекты
- `make_assets2.py` — векторные фоны/кнопки/иконки (резерв)
- `make_demo.py` — сборка браузерной демки (картинки внутрь как data URI)

## Размер APK
603 КБ. Звук — самый тяжёлый ресурс (музыка 125 КБ), фоны по 55–73 КБ.
Подпись: v1 (JAR) + v2, minSdk 21 — ставится на старые устройства
(Redmi Note 4, Android 7), быстрее сканируется при установке.
